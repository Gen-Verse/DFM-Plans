# DFM Plans

### Discovery Foundation Models 研究路线图与开发者入口

[English](README.md) · [研究路线图](ROADMAP.md) · [贡献指南](CONTRIBUTING.md)

这个仓库用于展示 **Discovery Foundation Models（DFMs）** 未来的研究方向、技术开源、Demo 与开发者协作机会。

DFM 的整体愿景、科学背景、科学家合作计划和申请入口将由官方网站承接，相关链接上线后会放在这里。这个仓库只负责呈现技术研究版图。

## 如何理解这个仓库

下面的方向通过 DFM discovery loop 在**概念上相互关联**，但不要求共享同一套代码、统一接口或组成一个完整工程系统。每个方向都可以由不同团队独立研究、独立评测和独立开源。

这些目录只是对未来研究范围的公开预留。目录存在不代表对应实现已经发布。

## 未来研究方向

| 方向 | 主要内容 |
| --- | --- |
| [Proposer](proposer/) | 问题发现、问题定义、表征构建与假设形成 |
| [Experimenter](experimenter/) | 干预、实验、工具调用、模拟环境以及 Dry/Wet Grounding |
| [Reviser](reviser/) | 验证、实验证据、反证、失败归因与基于证据的修正 |
| [Continual Improvement](continual-improvement/) | Discovery Skill、Memory Evolution、跨任务迁移与持续发现能力提升 |
| [Training](training/) | 数据构建、Trajectory、SFT、RL、Process Supervision 与 Scientific Post-training |
| [Evaluation](evaluation/) | 模块能力、Discovery Process、Transfer、Efficiency 与真实发现验证 |
| [Demos](demos/) | 不同科学和工程领域中的独立案例与演示 |

每个方向都可以进一步产生独立的论文、代码仓库、模型、数据集、Benchmark 或 Demo。正式发布的资产会统一链接到对应目录和 [ROADMAP.md](ROADMAP.md)。

## 从这里开始

- 在 [ROADMAP.md](ROADMAP.md) 查看各方向当前状态。
- 通过 [GitHub Issues](../../issues) 提出技术问题、研究建议和开源合作。
- 发起项目或提交成果前，请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。
