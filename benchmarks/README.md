# DFM Benchmarks

Benchmark development for Discovery Foundation Models.

We are interested in tasks that withhold or corrupt structures the system is expected to construct: questions, variables, representations, mechanisms, interventions, or evaluators.

Planned benchmark families include process-centered, interactive, simulation-grounded, and domain-grounded discovery tasks.

**Status:** open for benchmark proposals. See [`../OPEN_PROBLEMS.md`](../OPEN_PROBLEMS.md).
