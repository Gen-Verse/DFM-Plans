# DFM Community

**DFM Community** is the long-term network connecting AI researchers, domain scientists, infrastructure builders, research labs, companies, and real-world discovery environments.

**DFM Commons** is the open resource layer the community builds and shares: algorithms, infrastructure, environments, benchmarks, datasets, open problems, and reproducible artifacts.

Planned community layers:

- [`funded_challenges/`](funded_challenges/) — selected open problems with dedicated support
- [`partners/`](partners/) — announced academic, domain, infrastructure, and industry collaborations

See [`../COLLABORATE.md`](../COLLABORATE.md) for collaboration routes.
