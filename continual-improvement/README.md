# Continual Discovery Improvement

**Status: Planned**

This direction studies how reusable discovery operations can be learned across tasks, retained as skills or memory, and improved through repeated research experience.

## DFM Capabilities

- Continual Discovery Improvement
- Cross-task transfer
- Discovery Skill and Memory Evolution

## Planned Work

- reusable discovery skills;
- experiential and working memory for research;
- validation-gated skill updates;
- cross-task and cross-domain transfer;
- bounded recursive improvement of discovery processes.

This direction concerns continual improvement as a research capability, not a requirement that all DFM projects share one memory system.
