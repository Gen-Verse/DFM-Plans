# Domain Discovery

DFM Community connects frontier AI with real scientific and engineering domains.

A domain track can contribute problems, data, simulators, measurements, protocols, validators, experimental infrastructure, deployment settings, or expert knowledge.

Initial tracks are listed below; they are invitations, not claims that complete DFM systems already exist in these domains.

- [`biology/`](biology/)
- [`chemistry/`](chemistry/)
- [`materials/`](materials/)
- [`medicine/`](medicine/)
- [`robotics/`](robotics/)
- [`physics/`](physics/)
- [`mathematics/`](mathematics/)
- [`climate/`](climate/)
- [`ml_research/`](ml_research/)
- [`social_science/`](social_science/)

To bring a new domain, use the Domain Proposal issue template or see [`../COLLABORATE.md`](../COLLABORATE.md).
