# Discovery Environments

**Status: environment scaffold — contributions are welcome.**

DFM environments should expose incomplete research structure and return consequences the proposing system does not control.

- [`digital/`](digital/) — code, formal systems, ML research, software, and agent environments
- [`simulation/`](simulation/) — causal worlds, mechanistic simulators, digital twins
- [`physical/`](physical/) — embodied, laboratory, instrument, and human-mediated environments

Good environments can hide variables, contain observationally equivalent mechanisms, include evaluator mismatch, or require active intervention and revision.
