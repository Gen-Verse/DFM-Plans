# JEPA-Anything

**English** · [中文](README_CN.md)

**Scientific World Models**

Scientific world models exploring representations of scientific states and predictions of how those states change under interventions across domains.

- **Repository:** [Gen-Verse/JEPA-Anything](https://github.com/Gen-Verse/JEPA-Anything)
- **Paper:** [JEPA-Anything: Learning Predictive Models across Different Worlds](https://arxiv.org/abs/2609.20800)
- **Released:** 2026-09-18
- **Availability:** Technical report and research code
