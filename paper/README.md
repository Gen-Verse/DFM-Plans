# Paper

This directory contains the current manuscript source snapshot of:

**Discovery Foundation Models: Toward Open-Ended Discovery Intelligence**

`Discovery_Foundation_Models.tex` is preserved as the latest source supplied to this repository package. It is **not a standalone compilation bundle**: the original project also depends on files such as the document class, `references.bib`, and manuscript figures/assets that are not included in the current upload set.

Add the complete paper project here when it is ready for public release.
