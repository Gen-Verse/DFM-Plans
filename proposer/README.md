# Proposer

**Status: In Development**

This direction studies how a model can move beyond answering predefined questions and instead identify potentially valuable patterns, formulate researchable problems, construct useful representations, and generate testable hypotheses.

## DFM Capabilities

- Problem Discovery
- Problem Formulation
- Representation Construction
- Hypothesis Formation

## Planned Work

- proposer task and data formulations;
- post-training methods for discovery-oriented proposal generation;
- novelty, value, plausibility, and testability evaluation;
- applications to longitudinal and structured scientific data;
- reproducible proposer demos and open-source releases.

Projects in this direction may be developed and released independently from other DFM directions.
