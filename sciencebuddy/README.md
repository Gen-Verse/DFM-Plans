# ScienceBuddy

**English** · [中文](README_CN.md)

**Scientist Interaction**

ScienceBuddy is an interactive scientific workspace connecting researcher dialogue, scientific tools, execution records, and inspectable artifacts. Its recursive-in-recursive self-improvement framework couples an inner loop that refines the agent harness with an outer loop that trains the model.

- **Released:** 2026-09-16
- **Availability:** Preview workspace, technical report, and research experiment code
- **Product:** [ScienceBuddy Preview](http://science-buddy.io/)
- **Paper:** [ScienceBuddy: Recursive-in-Recursive Self-Improvement for Interactive Scientific Agents](https://arxiv.org/abs/2609.17523)
- **Repository:** [Gen-Verse/ScienceBuddy](https://github.com/Gen-Verse/ScienceBuddy)
- **Research documentation:** [Algorithm](https://github.com/Gen-Verse/ScienceBuddy/blob/main/docs/algorithm.md) · [Experiments](https://github.com/Gen-Verse/ScienceBuddy/blob/main/docs/experiments.md)

Within the DFM agenda, ScienceBuddy explores how scientific collaboration supplies experience for improving both working procedures and model capabilities. The public repository contains the simplified RSI experiment implementation; the hosted product's full source is not included.

This page is the project entry in the DFM research index. Technical documentation and release updates are maintained in the independent repository. Milestones are tracked in [Research Progress](../README.md#research-progress).
