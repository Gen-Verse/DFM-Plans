# ScienceBuddy

[English](README.md) · **中文**

**科学家交互 · AI 科研搭档**

ScienceBuddy 是连接科研对话、科学工具、执行记录与可检查研究产物的交互式科研工作空间。其递归嵌套的自我改进框架，通过内循环优化 Agent Harness，通过外循环训练模型，探索两者的协同改进。

- **发布日期**：2026-09-16
- **开放状态**：预览产品、技术报告与研究实验代码已发布
- **产品入口**：[ScienceBuddy Preview](http://science-buddy.io/)
- **论文**：[ScienceBuddy: Recursive-in-Recursive Self-Improvement for Interactive Scientific Agents](https://arxiv.org/abs/2609.17523)
- **独立仓库**：[Gen-Verse/ScienceBuddy](https://github.com/Gen-Verse/ScienceBuddy)
- **研究文档**：[算法说明](https://github.com/Gen-Verse/ScienceBuddy/blob/main/docs/algorithm.md) · [实验指南](https://github.com/Gen-Verse/ScienceBuddy/blob/main/docs/experiments.md)

在 DFM 研究体系中，ScienceBuddy 探索如何将科学家协作转化为学习经验，持续改进工作流程与模型能力。公开仓库提供简化的 RSI 实验实现，未包含托管产品的完整源码。

本页是 DFM 研究索引中的项目入口。具体技术文档与版本更新由独立仓库维护，里程碑统一记录在[研究项目与进展](../README_CN.md#研究项目与进展)中。
