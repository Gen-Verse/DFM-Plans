# ScienceIDE

**Scientific Environments · 科学环境 · 科学集成开发平台**

A scientific development platform for executable, verifiable, and reusable environments that support agent execution and model training.

将科学工具、任务与验证标准组织为可执行、可验证、可复用的环境，支持 Agent 执行与模型训练。
