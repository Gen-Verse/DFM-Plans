# ScienceIDE

**English** · [中文](README_CN.md)

**Scientific Environments**

ScienceIDE turns scientific code and expert-defined acceptance criteria into executable, verifiable learning environments. These environments provide interaction trajectories for supervised fine-tuning, rewards for reinforcement learning, and evidence for evaluation.

- **Released:** 2026-09-17
- **Availability:** Technical report, preview code, selected environments and tasks, and PhAI-IDE-4B/9B/72B models
- **Paper:** [ScienceIDE: Turning World's Scientific Codebase into Agent Learnable Environments](https://arxiv.org/abs/2609.19134)
- **Repository:** [aitofound/ScienceIDE](https://github.com/aitofound/ScienceIDE)
- **Models:** [ScienceIDE Model Series](https://huggingface.co/collections/AItonomy/scienceide-model-series)
- **Project page:** [ScienceIDE](https://aitonomy.org/projects/scienceide)
- **Learning infrastructure:** [Gen-Verse/ScienceInfra](https://github.com/Gen-Verse/ScienceInfra)

Within the DFM agenda, ScienceIDE supplies reusable scientific environments and verifiable feedback for agent learning. The study reports improvements in held-out scientific-code repair and selected general-purpose benchmarks. ScienceInfra develops the reusable training and evaluation infrastructure underlying this work.

This page is the project entry in the DFM research index. Technical documentation and release updates are maintained in the independent repositories. Milestones are tracked in [Research Progress](../README.md#research-progress).
