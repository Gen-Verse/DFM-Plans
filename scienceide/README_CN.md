# ScienceIDE

[English](README.md) · **中文**

**科学环境 · 科学集成开发平台**

ScienceIDE 将科学代码与专家定义的验收标准转化为可执行、可验证的学习环境，为监督微调提供交互轨迹，为强化学习提供奖励，并为评测提供执行证据。

- **发布日期**：2026-09-17
- **开放状态**：技术报告、预览代码、部分科学环境与任务，以及 PhAI-IDE-4B/9B/72B 模型已发布
- **论文**：[ScienceIDE: Turning World's Scientific Codebase into Agent Learnable Environments](https://arxiv.org/abs/2609.19134)
- **独立仓库**：[aitofound/ScienceIDE](https://github.com/aitofound/ScienceIDE)
- **模型系列**：[ScienceIDE Model Series](https://huggingface.co/collections/AItonomy/scienceide-model-series)
- **项目主页**：[ScienceIDE](https://aitonomy.org/projects/scienceide)
- **学习基础设施**：[Gen-Verse/ScienceInfra](https://github.com/Gen-Verse/ScienceInfra)

在 DFM 研究体系中，ScienceIDE 提供可复用的科学环境与可验证反馈，支撑智能体学习。论文报告了留出科学代码修复任务及部分通用基准上的能力提升。ScienceInfra 持续建设支撑这项工作的可复用训练与评测基础设施。

本页是 DFM 研究索引中的项目入口。具体技术文档与版本更新由独立仓库维护，里程碑统一记录在[研究项目与进展](../README_CN.md#研究项目与进展)中。
