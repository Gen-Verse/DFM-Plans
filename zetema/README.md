# Zetema

**Status: system scaffold — components will be released progressively.**

Zetema is the reference system organization for Discovery Foundation Models. It connects within-task research-state revision, verification and experimental gating, external grounding, and validated cross-task Discovery Skill evolution.

## Planned Components

- [`research_state/`](research_state/) — explicit, revisable research state
- [`discovery_loop/`](discovery_loop/) — within-task discovery operations and branching
- [`world_model/`](world_model/) — Research World Models for outcome, cost, and risk prediction
- [`verification/`](verification/) — process verification and experimental gating
- [`memory/`](memory/) — Discovery Skill Memory and cross-task evolution
- [`grounding/`](grounding/) — Dry-Lab / Wet-Lab and external-environment interfaces

Contributions and alternative implementations are welcome. See [`../OPEN_PROBLEMS.md`](../OPEN_PROBLEMS.md) and [`../CONTRIBUTING.md`](../CONTRIBUTING.md).
